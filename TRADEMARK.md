## Allowed uses

You may use the marks without asking when you are:

- Referring accurately to this project or its releases (for example, "WRM Pro Enterprise v14.0.0").
- Stating that your software is compatible with, or built to run with, WRM (for example, "for use with WRM Pro").
- Making a factual statement about interoperability, as long as it does not imply endorsement.
- Linking to the repository at `https://github.com/vedranius/wrm-pro-enterprise`.

In all of these cases, use the marks as adjectives followed by the product name, not as nouns or verbs, and do not imply a formal relationship.

## Disallowed uses

You may **not**:

- Use "WRM", "WRM Pro", or "WRM Pro Enterprise" as the primary name of a fork, distribution, or derivative project in a way that implies the steward endorses it.
- Use the mark in the name of a competing product.
- Use the marks in a domain name, social handle, or product name that could be confused with the official project.
- Use the logo in a way that suggests sponsorship, endorsement, or affiliation without written permission.
- Alter or imitate the logo to mislead users about origin.

## Forks

Forks and derivative distributions must use a different name. You may state that your project is a fork of or based on WRM, but the fork's own name and branding must clearly distinguish it from the official project.

For permission to use the logo, or for any question not covered here, open an issue in the repository or contact the steward through GitHub.
