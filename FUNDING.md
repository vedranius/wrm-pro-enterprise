# Funding

WRM Pro Enterprise is free software under the Apache License 2.0. The code has no price. Keeping
it secure, reviewed and maintained does — so this page says what the work costs, where the money
comes from, and how it is spent.

## What it costs (indicative, per year)

| Item | Scope | Notes |
|---|---|---|
| Maintenance | 0.5–1.0 FTE | bug fixes, dependency updates, security patches |
| Security review | 0.1–0.2 FTE | a second person on the critical path |
| Penetration test | 1–2 weeks | once a year |
| Infrastructure | 2–5 k EUR | CI, hosting, SIEM |
| Legal | one-off + yearly | CLA, trademark, contracts |
| Bug bounty | optional | from Phase 6 onward |
| Community | 0.1 FTE | docs, translations, events |

## Where the money comes from

1. **Support and SLA** — companies pay for a guaranteed response and a support contract, not for
   the code (see [SUPPORT.md](SUPPORT.md)).
2. **Hosted / enterprise** — permitted by Apache-2.0; anyone may run a hosted service, so the
   value has to be in operation, not lock-in.
3. **Sponsorship** — GitHub Sponsors / Open Collective; realistically covers a small part.
4. **Foundations** — OpenSSF Alpha-Omega, Sovereign Tech Fund, NLnet; a good fit for the security
   work specifically.
5. **A strategic company decision** — "we fund X FTE because it reduces our own risk and keeps us
   influence"; this belongs in a budget, not in gratitude.

## Transparency

- A public funding page states what each source is spent on.
- An annual report publishes: releases, advisories, time-to-patch, and the number of maintainers.
- Sponsorship has a spending policy: money never buys a merge or a feature priority
  ("no pay-to-merge").

## Current status

No funding is in place yet. Until a source covers at least half the maintenance cost, the
steward funds the project personally.
