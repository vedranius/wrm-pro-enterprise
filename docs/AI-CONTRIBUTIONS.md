# AI-Assisted Contributions

This policy governs contributions that were produced or assisted by AI tools (code assistants, large language models, and similar).

## Disclosure

- You must disclose when a contribution was generated or materially assisted by AI. State this in the pull request description.

## Review

- You are responsible for the correctness, security, and quality of AI-assisted code. Review the output as if you wrote it yourself.
- Do not submit code you do not understand. If you cannot explain a change, do not submit it.

## Provenance and licence

- Do not paste third-party or unknown-licence code into a contribution. AI tools may reproduce training data whose licence is unknown or incompatible.
- You must have the right to contribute everything you submit. AI output that reproduces code you do not have the right to license must not be included.
- If you are unsure of the provenance of AI output, do not include it.

## CLA and DCO

- AI-assisted contributions are still subject to the `CLA.md` and the DCO `Signed-off-by` requirement.
- By signing off, you affirm the same warranties as for hand-written code: that you have the right to contribute it and that it does not infringe third-party rights.

## Copyright and SPDX

- The same SPDX and copyright rules apply to AI-assisted code as to any other contribution.
- AI is not an author under copyright law; the human contributor remains the author and assumes responsibility.

## Licence of the contribution

- AI-assisted code is contributed under the same Apache-2.0 terms as all other code.
