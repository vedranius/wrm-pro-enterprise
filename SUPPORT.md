# Support

## Community support

WRM is a community project. Support is provided on a best-effort, voluntary basis through:

- **GitHub Discussions** — questions, usage help, and general discussion: `https://github.com/vedranius/wrm-pro-enterprise/discussions`
- **GitHub Issues** — bug reports and feature requests: `https://github.com/vedranius/wrm-pro-enterprise/issues`

Before posting, search existing issues and discussions to avoid duplicates.

## Security issues

Do not report security vulnerabilities in public issues. Use the private vulnerability reporting feature on the repository (Security → Report a vulnerability). See `docs/PSIRT.md` for the full process.

## No SLA or warranty

Community support carries **no service-level agreement** and **no warranty**. The software is provided AS IS under the Apache License, Version 2.0. There is no commitment to a response time for community support.

## Commercial support

Commercial support, custom development, and managed deployments are available under separate
terms from the project steward. These terms are independent of the Apache-2.0 licence and are
not priced in this repository. A support contract covers:

- **Guaranteed response times**, by severity, aligned with the PSIRT targets in
  `docs/PSIRT.md`.
- **A named support channel** (private ticket/email) instead of public Discussions.
- **Security patches and backports** to the supported minor versions.
- **Upgrade and migration assistance** through the checklists in `docs/MIGRATIONS.md` and
  `docs/RELEASE.md`.

The contract is for a *response* and *assistance*, never for a change to the licence or to what
is published in this repository. To inquire, contact the steward through GitHub.
